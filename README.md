# Portfolio Dev

Personal developer portfolio built with HTML, CSS and JavaScript.

The project is focused on presenting my background, selected projects, areas of work and contact information in a simple, responsive interface.

## Current structure

- Introductory profile section
- Technology stack highlights
- Featured projects section
- Services and areas of work
- Contact section
- Responsive layout and section navigation

## Tech stack

- HTML5
- CSS3
- JavaScript

## Status

This portfolio is still being refined. Some project cards and contact links are placeholders while the final portfolio content is being consolidated.

The repository is public to show the implementation and UI work, but the profile README and selected fullstack repositories are the primary portfolio references.
